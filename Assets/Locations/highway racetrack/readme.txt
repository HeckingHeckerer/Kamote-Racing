	-Building-
just select the track curve and press "tab". press "E" to extrude press. "N" and press a segment to change the radius and tilt

	-Exporting-
click file then export fbx. in object type only select mesh then export

	-Importing to Unity-
1. import the model and texture into unity.
2. in the textures inspector change the filter mode to "point (no filter)" and the compression to "none" for transparent textures check "alpha is transparency"
this will prevent the textures from being blury and compressed.
3. make materials and use the textures for them set materials render mode to "cutout" that are suppose to be transparent(dont do it to all)
4. in the inspector of the mesh materials tab set the textures to the objects.
